# 动作触发与衔接（0.1.0）

原生 Windows / Linux Qt Helper、macOS Helper 使用同一份动作清单（`assets/pet-manifest.json`）。
页面内角色同步任务状态与完成提示，不播放随机待机动作和鼠标互动。

帧画布为 256 × 352，24 fps（运行时 42 毫秒／帧）。素材裁在小腿处，每帧底部有一段渐隐，不是缺图。

| 动作 | 触发与频率 | 播放和衔接 |
| --- | --- | --- |
| idle 待机 | 空闲或断开连接时 | 8 秒循环（192 帧）；断开时由状态气泡说明连接问题 |
| thinking 思考 | DSH 回合开始、工具结束后继续整理 | 8 秒循环；重复同类事件不会重播起点 |
| working / working_search / working_command | 工具调用；根据搜索、编辑、命令、测试活动选择 | 8 秒循环；更新任务时立即切换到最新状态 |
| waiting 等待 | 等待批准或回答时 | 8 秒循环，直到等待解除 |
| success 完成 | 一轮任务完成时 | 播一次 4 秒（96 帧）；重复完成提示合并，新的任务可立即打断 |
| error 出错 | 工具临时失败或回合出错 | 播一次 3 秒（72 帧）；临时失败返回当前工作，持续错误保持末帧，直到状态改变 |
| dragging 悬空拖拽 | 鼠标拖动角色时 | 8 秒循环（192 帧），拖到一半不会自行落地 |
| dragging_release 松手落地 | 拖拽结束时 | 播一次 1.5 秒（36 帧），再回最新任务状态；重新拖拽立即接管 |
| head_pat 摸头 | 点击头部；双击同样触发 | 播一次 3 秒（72 帧）；动作期间不接受另一个点击动作，状态打断后仍保留 1.2 秒点击冷却 |
| poke 戳一下 | 点击身体 | 播一次 2.5 秒（60 帧），规则同上 |
| wings 碰翅膀 | 点击身体左右两侧的翅膀 | 播一次 2.5 秒（60 帧），规则同上 |
| idle_yawn / idle_glance / idle_hum | 仅空闲时随机选择，不连续重复上一段 | 分别 4 秒（96 帧）、4 秒（96 帧）、5 秒（120 帧）；播完再开始休息计时，安静 45～90 秒、标准 25～45 秒、活泼 12～22 秒 |

共 16 个片段、2,052 帧：7 个循环片段各 192 帧，其余 9 个单次片段合计 708 帧。

## 优先级与绘制

- 拖拽和落地保护当前鼠标动作；DSH 状态持续更新，落地后显示最新状态。
- 工作、等待和错误消息立即打断待机／点击动作；完成提示接管装饰动作。
- 点击不插入正在播放的完成／错误提示；待机动作只在空闲且没有其他动作时触发。
- 同一片段的连续帧直接绘制，不叠加呼吸缩放、摇摆或逐帧淡化。不同动作之间使用 100 毫秒淡化；拖拽相关切换直接绘制。
- 完成和错误提醒不抖动整个窗口。气泡、余额和任务列表变化保留角色坐标；Qt 在屏幕顶部空间不足时将气泡放到角色下方。
- “减少动态”固定角色姿势，关闭随机待机／点击动画，完成提示按消息原始时长显示；状态与余额继续更新。

## 素材核对与复现

动作帧由 `tools/render` 的分层渲染器离线生成，时间轴在 `tools/render/clips.mjs`。循环片段长 8 秒，周期运动量化到整周期，首尾无缝。清单 `assets/pet-manifest.json` 记录每个片段的帧列表、是否循环和渲染参数。

```powershell
cd tools/render
npm install
npx playwright install chromium
node render.mjs            # 全部片段，并重写清单
node render.mjs idle poke  # 只重渲染指定片段，不改清单
cd ../..
npm test
npm run test:python
```
